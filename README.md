# CT Edu — abdominal anatomy learning prototype

CT Edu is an early-stage web app for medical students. The first lesson now supports navigation through the 113-slice axial CT volume from the SPL Abdominal Atlas with its matching segmentation volume. The interface defaults to Persian (RTL), supports English (LTR), and keeps bilingual anatomy names available.

## Included in this milestone

- index.html: responsive anatomy-learning workspace.
- src/data/anatomy.js: nine bilingual anatomical structures mapped to the atlas's authoritative segment IDs for the selected slice.
- src/viewer/ct-slice-viewer.js: browser canvas renderer; loads the selected axial slice and its lossless RGB-encoded segment-ID image on demand, then draws the overlay and labels from the active UI state.
- src/quiz/quiz-engine.js: four-option active-recall quiz logic.
- src/app.js and src/styles.css: Persian/English interface, independent labels and overlays, per-structure visibility, zoom/reset, structure selection, emphasis presets and session score.
- assets/spl-abdominal-demo/: a committed single-slice fallback. The full stack (113 CT PNGs + 113 label-ID PNGs + `volume.json`) is generated by `scripts/build_demo_assets.py` for local viewing and CI/Pages builds.
- data-license.html and licenses/SPL-Abdominal-Atlas-LICENSE.txt: source attribution and full referenced license notice.
- scripts/: archive inventory, source metadata inspection, and reproducible volume/slice asset preparation scripts.
- tests/: built-in Node tests for search, segment-ID mapping, quiz logic, source assets, quiz accessibility and axial-viewer controls/API.
- .github/workflows/test.yml: read-only CI checks and a review artifact for the generated 113-slice volume.

## Data, orientation and scope

- Source: **SPL Abdominal Atlas**, September 2015, by Florin Talos, Marianna Jakab and Ron Kikinis; Surgical Planning Laboratory, Brigham and Women's Hospital / Harvard Medical School.
- This lesson renders slice k=26 (zero-based) from Data/I.nrrd, with its paired Data/seg.nrrd labelmap.
- Both NRRD headers report 256×256×113 volumes and matching LPS coordinate space, direction vectors, spacing and origin. The CT and labelmap are flipped vertically in the same way in the slice-preparation step so anterior appears at the top while the left/right display convention remains consistent.
- The grayscale window and color presentation are modified for web-based teaching. Source segment IDs are preserved losslessly in each label PNG as ID = R + 256 × G. The source in-plane matrix is only 256×256 (about 0.94 mm in-plane spacing) with 1.5 mm slice spacing: changing slices adds coverage, not detail within each image. Do not interpolate or upscale this source and describe it as higher resolution.
- The viewer now navigates all 113 axial slices using the slider, previous/next controls, mouse wheel over the image, or Up/Down keys. Coronal/sagittal multiplanar reconstruction (MPR), adjustable raw-voxel window/level, and true DICOM-series ingestion are not implemented yet. Emphasis presets change the visual emphasis of the current axial slice.
- An anatomy educator/radiologist should review anatomy naming and orientation before external educational release. The current preview has been visually checked against the matching atlas labelmap, but it is not clinically validated.
- Source license terms and the third-party-material caveat are documented in DATA_LICENSE_REVIEW.md and data-license.html. Check those terms before redistributing additional data or third-party components.

**Educational use only. Not for diagnosis or clinical decisions.**

## Run locally

Requires Node.js 18+ for tests and Python 3 plus `numpy`/`Pillow` to generate the slice stack. Build the browser-ready assets before starting the local server:

~~~bash
python3 -m pip install numpy pillow
python3 scripts/build_demo_assets.py --output assets/spl-abdominal-demo
python3 -m http.server 8000
~~~

Open http://localhost:8000.

Run tests:

~~~bash
npm test
~~~

Inspect the uploaded source archives without extracting or modifying them:

~~~bash
npm run inspect-data
python3 scripts/read_atlas_metadata.py
~~~

Generate the browser-ready 113-slice teaching volume (requires numpy and Pillow):

~~~bash
python3 -m pip install numpy pillow
python3 scripts/build_demo_assets.py --output assets/spl-abdominal-demo

For a disposable review artifact instead of updating the local asset directory, use `python3 scripts/build_demo_assets.py --output build/ct-demo-volume`
~~~

The source ZIPs are read in place and are not changed by these scripts. Before public release, a separate review must confirm redistribution rights for every source archive and any third-party material; the current dataset's 256×256 in-plane resolution is also a release-quality limitation that requires an appropriately licensed higher-resolution source if higher detail is essential.
